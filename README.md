# Spec Driven Development — Beyond the Vibes

A presentation about Spec Driven Development (SDD): a methodology for writing structured specifications before code to enable better AI-assisted development, clearer stakeholder communication, and fewer iteration traps.

Open `spec-driven-development.html` in your browser to view the presentation.
